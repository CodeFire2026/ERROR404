# Funciones descriptivas en JavaScript

En JavaScript es recomendable utilizar nombres de funciones que sean claros y descriptivos. Generalmente se utiliza Camel Case, comenzando con minúscula y colocando en mayúscula la primera letra de cada palabra siguiente.

**Por ejemplo:** `calculateTotalPrice()`.

De esta forma, con solo leer el nombre de la función podemos tener una idea de la tarea que realiza.

---

## Conclusión

Utilizar nombres descriptivos para las funciones permite que el código sea más fácil de leer y entender. Un buen nombre debería indicar qué acción realiza la función y sobre qué elemento trabaja.

Además, respetar el formato Camel Case y utilizar nombres claros en inglés facilita el trabajo entre desarrolladores y permite mantener el código organizado y comprensible.
